# Model Lab L2 — 15m: A01's recipe on 15-minute bars (A05), 2026-10-18

Run: `runs/A05_15m_logit_t1z5.md` (pooled logistic, all factors, target `t1z_min_k5` = deep vol-scaled zigzag lows;
PIT top-100 by traded value 2016→, 208 names with 15m data, 203 scored; expanding, 6-month test windows, min train 2Y;
19 folds 2017→2026). Production reference = LR-Extrema P(min) replayed with **global 15m params** on the same bars.

Same shape as A01 on day bars: the recipe finds swing lows clearly better than production, on both timeframes.

A05 does **not** have the "bigger moves after picks" second leg.

## Caveats
- 15m QA file (`qa_15minute.csv`) was never produced, so the ex-QA line is skipped.
- Survivorship (TD-022) applies, but A05's picks are not move-rich, so it is not what flatters this result.
- 5-day horizon only (the middle T5 horizon for 15m); the 500-bar (~20-day) horizon is in the targets but not in the
  after-pick table.

## Reading
Detection quality transfers to 15m; payoff does not. Consistent with production's own history (15m names earn less
per rupee-day than day/4h names): short-timeframe lows are real but shallow. Next 15m step, if any, is a magnitude or
deep-move target on 15m, not more low-finding.
