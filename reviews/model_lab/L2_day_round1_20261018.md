## Caveats

1. **Scorer: short-window truth saturates.** Match tolerance on day = 3 bars, equal to the smallest window (`t1w_w3`):
   a coin reaches AP 0.41 there. Tolerance should scale with the truth window (e.g. ≤ w/2) — fix before relying on
   short-window truths.
2. After-pick returns overlap in time (20-day windows; market-wide rebounds cluster picks) — no formal significance
   test yet; per-year consistency is the guard used.
3. Survivor-biased universe (current instrument list) — affects every model and reference alike.
4. Production's live day-TF stocks trade `dayagg` bars (09:15–15:15); this round used native day bars.
5. `t3_sig` divides by σ = 0 on flat (suspended) stretches → inf values (warning); harmless to the verdicts, to fix.
6. Model level only. Nothing here says a strategy built on A01 makes money; that is the later strategy study.
